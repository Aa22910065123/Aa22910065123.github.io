02

角色与 IP 视觉· 一套人，多种光

同一个角色在四种光位下的定妆：顶部暖光、青色侧逆、霓虹混光、硬光特写。 这些不是"好看的图"，是分镜阶段要用的参考——先定脸、定发、定体型，后面换场景换服装才不会崩。

用途 角色定妆 / 分镜参考 一致性 同脸同发同体型 光位 4 组
03

一致性换衣· 从人台到上身

左边是服装实拍（人台、灰背景、真实褶皱和开叉），右边是同一条裙子穿在模特身上的成片。 难点不在"换件衣服"，在于版型、垂坠、褶皱走向、开叉高度、披肩的透视都要跟着原物走—— 这是电商和服装品牌最愿意付费的一环：不用请模特、不用搭景、一次出多版。

输入 服装实拍 + 人物底图 保留 版型 / 褶皱 / 开叉 / 面料 批量 单角色 60+ 资产
BEFORE · 服装实拍
AFTER · 上身成片
鼠尾草绿抹胸开叉长裙 · 同色薄纱披肩 版型、扭结、开叉位置逐项对齐原物

这套产线怎么被 Agent 自动跑起来、成片怎么按服装 / 机位 / 场景自动入库（带 seed 可回溯），见 06 · Agent 与产线。

04

文生图与角色设定· 一次出齐四视角

做 IP 最费时的不是画一张好看的图，是让"正面 / 背面 / 侧面 / 脸部特写"出现在同一张板上、 同一个人、同一套服装。这张四宫格设定板就是后续所有分镜的锚：任何人拿到它， 都能照着把角色画回来。

产出 四视角设定板 用途 分镜参考 / 换装基准 本地推理 无云端依赖
05

商业物料· 让模型排版，而不是只画图

海报是最能看出"会不会用"的一层：画面再美，字歪了、层级乱了就是废稿。 这三张的关键是文字——「五折」的毛笔笔锋、标签条的斜切、竖排小字的行距， 都是在生成阶段一次成型的，不是后期贴上去的。

类型 电商促销 / 产品宣发 难点 中文大字排版 用途 可直接投放
PRODUCT STILL

产品图走的是另一条路：不追求叙事，只追求材质可信——链条的金属反光、混凝土的颗粒、 投影的软硬边界。这张用单侧硬光压出高对比，背景沉到近黑，让产品自己发光。

06

Agent 与产线· 一句话交出去，它自己跑完整条链

这一层才是真正的差别：我把 ComfyUI 和无限画布都接进了 DSH（DeepSeek Harness）—— 不是把几个软件并排放着，而是让 Agent 成为「能动手」的那一层。给它一句话，它自己在画布上建剧本节点、 拆分镜、调 ComfyUI 的节点图出图、把结果写回成片节点；人只在画布上做两件事：看，和改。 下面几张就是它干活时的实况。
